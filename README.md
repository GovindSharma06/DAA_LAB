Design and Analysis of Algorithms (DAA) Lab
📚 About the Repository

This repository contains the C++ implementations of various algorithms covered in the Design and Analysis of Algorithms (DAA) laboratory.

The objective of these experiments is to understand different algorithm design techniques, implement them using C++, and analyze their time and space complexities.

Each experiment contains a separate implementation of the given problem statement.

🧪 List of Experiments
Experiment 1: Sorting Algorithms

Aim: To implement Merge Sort, Quick Sort, Bubble Sort, Selection Sort, and Heap Sort using arrays as a data structure and analyze their time complexity.

Algorithms covered:

Merge Sort
Quick Sort
Bubble Sort
Selection Sort
Heap Sort
Experiment 2: Searching Algorithms

Aim: To implement Linear Search and Binary Search and analyze their time complexity.

Algorithms covered:

Linear Search
Binary Search
Experiment 3: Strassen's Matrix Multiplication

Aim: To implement Strassen's Matrix Multiplication algorithm and analyze its time complexity.

Experiment 4: Huffman Coding

Aim: To implement Huffman Coding and analyze its time complexity.

Experiment 5: Minimum Spanning Tree (MST)

Aim: To implement Minimum Spanning Tree using Prim's and Kruskal's algorithms and analyze their time complexity.

Algorithms covered:

Prim's Algorithm
Kruskal's Algorithm
Experiment 6: Dijkstra's Algorithm

Aim: To implement Dijkstra's algorithm for finding the shortest path in a weighted graph and analyze its time complexity.

Experiment 7: Bellman-Ford Algorithm

Aim: To implement the Bellman-Ford algorithm for finding shortest paths in a weighted graph and analyze its time complexity.

Experiment 8: N-Queens Problem

Aim: To implement the N-Queens problem using an algorithmic approach and analyze its time complexity.

Experiment 9: Longest Common Subsequence (LCS)

Aim: To implement the Longest Common Subsequence problem using Dynamic Programming and analyze its time complexity.

Experiment 10: String Matching Algorithms

Aim: To implement Naive String Matching, Rabin-Karp, and Knuth-Morris-Pratt (KMP) algorithms and analyze their time complexity.

Algorithms covered:

Naive String Matching
Rabin-Karp Algorithm
Knuth-Morris-Pratt (KMP) Algorithm
Experiment 11: Floyd-Warshall Algorithm

Aim: To implement the Floyd-Warshall algorithm for finding all-pairs shortest paths and analyze its time complexity.

Experiment 12: 0/1 Knapsack Problem

Aim: To implement the 0/1 Knapsack problem using Dynamic Programming and analyze its time complexity.

🛠️ Technologies Used
Programming Language: C++
Data Structures: Arrays, Graphs, Trees, Matrices
Algorithmic Techniques: Divide and Conquer, Greedy Method, Dynamic Programming, Backtracking
IDE/Compiler: VS Code / Code::Blocks / GCC
